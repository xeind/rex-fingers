rex-fingers puts letter hints over the paths, URLs, and hashes on a [Rex](https://www.superlogical.com/rex) pane. Type a hint and the match goes to your clipboard. This release adds a one-line install on a Mac and hints on the panes of a Rex host.

## Install on a Mac

```sh
curl -fsSL https://raw.githubusercontent.com/xeind/rex-fingers/main/scripts/install.sh | sh
```

The script fetches the tarball for your Mac, checks it against `SHA256SUMS`, and puts the plugin and the program in `~/.config/rex/plugins/rex-fingers`. It does not touch your Rex config: it prints the lines to add to `~/.config/rex/init.lua`. Then run `rex config check` and `rex config reload`. To update, run the same line again.

An install from v0.4.2 or before is a git clone, and the script refuses to replace it. Update the clone as the [README](https://github.com/xeind/rex-fingers/blob/v0.5.0/README.md#build-from-source) says, or move it away and run the script.

## New since v0.4.2

- Panes of a Rex host. `alt+f` and `alt+shift+f` work in a session on another machine, with nothing installed on that machine: its own `rex` runs a script the plugin sends with each run. Hints show after about 0.9 s on a host 200 ms away. A small box named `fingers` shows at the pane's top right corner while it reads the keys, and for 0.8 s after the pick: Rex for Mac snapshot 2107 dropped its connection to the host when the box closed at once. Close the hints with Esc, and stay on the tab while they are up.
- `host_keys` picks how a host's pane reads the keys. `"reader"`, the default, is the box above. `"mode"` and `"substitute"` are other ways, each with its own cost; the [README](https://github.com/xeind/rex-fingers/blob/v0.5.0/README.md#limits) lists them.
- `host_follow_scroll = true` hints the page a host's pane is scrolled to. The app's selection shows over the page for about a second, so it is off unless set.
- On a pane running `ssh`, `mosh`, or `et`, `:open:` and `:reveal:` copy the path, since it names a file on the other machine. URLs open as usual.
- A program older than the plugin now logs one "build it again" warning, instead of failing each pick with `flag provided but not defined`.

## The files under Assets

- `rex-fingers-v0.5.0-darwin-arm64.tar.gz` is for an Apple silicon Mac.
- `rex-fingers-v0.5.0-darwin-amd64.tar.gz` is for an Intel Mac.
- `SHA256SUMS` holds the checksums of the two tarballs. The install script checks them.
- GitHub adds the two "Source code" files to every release. You do not need them.

The program is signed ad hoc and not notarized. A copy fetched with `curl` runs; a tarball downloaded with a browser needs `xattr -dr com.apple.quarantine ~/.config/rex/plugins/rex-fingers` after you unpack it. There is no Linux build: [build from source](https://github.com/xeind/rex-fingers/blob/v0.5.0/README.md#build-from-source).
