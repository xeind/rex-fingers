rex-fingers puts letter hints over the paths, URLs, and hashes on a [Rex](https://www.superlogical.com/rex) pane. Type a hint and the match goes to your clipboard. It ports [tmux-fingers](https://github.com/Morantron/tmux-fingers) to Rex. This is the first release.

## Install on a Mac

1. Paste this into a terminal. It downloads the tarball for your Mac and unpacks it.

   ```sh
   V=v0.3.0; ARCH=$(uname -m | sed 's/x86_64/amd64/')
   mkdir -p ~/.config/rex/plugins
   curl -fsSL "https://github.com/xeind/rex-fingers/releases/download/$V/rex-fingers-$V-darwin-$ARCH.tar.gz" | tar -xz -C ~/.config/rex/plugins
   ~/.config/rex/plugins/rex-fingers/bin/rex-fingers version
   ```

   The last command prints `v0.3.0`.

2. Add this to `~/.config/rex/init.lua`:

   ```lua
   local dir = os.getenv("HOME") .. "/.config/rex/plugins/rex-fingers"
   local fingers = dofile(dir .. "/lua/rex-fingers/init.lua")
   fingers.setup{ binary = dir .. "/bin/rex-fingers" }
   ```

3. Run `rex config check`, then `rex config reload`.

Press `Alt-f` to hint the focused pane, or `Alt-Shift-f` to hint every pane of the window. A hint copies the match. Hold Shift to paste it, or Ctrl to open it.

## What the install puts on your Mac

One folder, `~/.config/rex/plugins/rex-fingers`, and nothing outside it:

- `bin/rex-fingers`, the program that finds the matches and draws the hints.
- `lua/rex-fingers/init.lua`, the plugin that Rex loads. It binds the keys and runs the program.
- `README.md` and `LICENSE`.

To remove rex-fingers, delete that folder and the three lines in `init.lua`.

## The files under Assets

- `rex-fingers-v0.3.0-darwin-arm64.tar.gz` is for an Apple silicon Mac.
- `rex-fingers-v0.3.0-darwin-amd64.tar.gz` is for an Intel Mac.
- `SHA256SUMS` holds the checksums of the two tarballs. You need it only to verify a download.
- GitHub adds the two "Source code" files to every release. You do not need them.

You need one tarball. The commands above fetch the right one. If you download a tarball with a browser, unpack it into `~/.config/rex/plugins`, then run `xattr -dr com.apple.quarantine ~/.config/rex/plugins/rex-fingers`. The program is signed ad hoc and not notarized, and macOS stops a quarantined copy without a message.

There is no Linux build. On Linux, [build from source](https://github.com/xeind/rex-fingers/blob/v0.3.0/README.md#from-source); only the unit tests have run there.

## Notes

- Tested with Rex for Mac 0.1.0 and CLI `0.1.0-preview.20`, in nushell, bash, and zsh.
- Hints are drawn in the pane itself, so no row is hidden. `overlay = "float"` draws them in a floating pane.
- `follow_scroll` is experimental. It hints the rows a scrolled pane shows, and it takes the clipboard for half a second to do so.
- Every option is in the [README](https://github.com/xeind/rex-fingers/blob/v0.3.0/README.md#configuration).
